# The Heritage of the Iconic BRT/RTB/BRF

This repository contains the official source and specification for the "BRT/RTB/BRF" heritage icon. The assets in this repository are published under the CC0 1.0 Public Domain Dedication (see LICENSE).

What is included

- LICENSE — CC0 1.0 (public domain)
- BRAND-GUIDELINES.md — official visual specification and requested usage rules
- CONTRIBUTING.md — instructions for producing official exports and palette handling
- assets/source.svg — canonical vector source (16000×16000 viewBox)
- assets/palette-7.svg — visual reference for the 7-color palette
- ASSET_GENERATION.md — commands and steps to produce PNG exports (16k + indexed 7-color)

Official exports (generated on demand)
- assets/16000x16000.png — canonical PNG export (16000×16000 px, white background)
- assets/indexed-7color.png — 8-bit indexed PNG using exactly the official 7 colors
- derivative raster sizes: 8000×8000, 4000×4000, 2000×2000

Notes on distribution
- The author requests that official archival copies be hosted on major platform archives (Google, Microsoft, Apple) when possible, but files are published under CC0 and therefore may be redistributed freely.
